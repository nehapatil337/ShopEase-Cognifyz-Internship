# ShopEase – E-Commerce Web Application

A full-stack e-commerce web application developed as part of the **Cognifyz Full Stack Development Internship**.

ShopEase demonstrates server-side rendering, form handling, validation, REST APIs, database integration, user authentication, API security, rate limiting, and background server-side tasks.

---

## 🚀 Features

- User registration and login
- Secure password hashing using bcrypt
- JWT-based user authentication
- Product management
- Add, update, delete, and search products
- Server-side form validation
- Client-side validation
- RESTful API endpoints
- SQL Server database integration
- External API integration
- API rate limiting
- Request logging middleware
- Background tasks using Node-Cron
- Responsive user interface using Bootstrap
- Server-side rendering using EJS

## 🗄️ Database

The application uses **Microsoft SQL Server** with the following main tables:

### Users
Stores registered user information and securely hashed passwords.

### Products
Stores product information including:

- Product ID
- Product Name
- Price
- Category
